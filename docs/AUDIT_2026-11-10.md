## 3. High. Stage 2 stops on TRF 4.09.1: its exit code on success is 253

```
  37  ls trf_parts/*.fa* | xargs -P "$T" -I{} sh -c 'trf "$1" 2 5 7 80 10 20 2000 -h -ngs > "$1.trf" 2> "$1.trf.err"; rc=$?; [ "$rc" -lt 127 ] || { echo "fs2: trf failed on $1 (exit $rc)" >&2; exit 255; }' _ {}
```
Measured: `trf X 2 5 7 80 10 20 2000 -h -ngs` on 1, 5, 42, 130 and 300 toy windows wrote 4, 17, 118, 331 and 869
repeat lines and exited 253 every time (Ubuntu package 4.09.1-6). `[ "$rc" -lt 127 ]` reads that as a crash, so
every part reports "trf failed (exit 253)" and `fs_all.sh` ends at stage 2. If the servers run the same TRF,
stage 2 has not run since this check was added (2026-10-19). Check there: `trf windows.fa 2 5 7 80 10 20 2000 -h -ngs > /dev/null; echo $?`.
A check that does not depend on the exit code: missing binary (already line 36), a signal (rc > 128 and no output),
or an output file without any `@` line.
