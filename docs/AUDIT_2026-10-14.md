# Pre-publication audit, 2026-10-14

Eight audits (step 1 / sear / satellites, steps 2–3, orchestrators and usability, report and plots, publish flow,
flankscan, tools and tests, bundled SubFam) were run on 37ce359 with synthetic genomes and the toy sets; the fixes
below were re-applied and re-tested on main (2afc55b). Earlier audits: AUDIT_2026-10-05.md, RELEASE_CHECK_2026-10-05.md.

## Open: needs the author's decision or more work

- **flankscan stage 9 fails its own toy** (`flankscan/tests/test_fs9.sh` now exits 1): all 40 hot-spot copies are
  called twins with the default `SOFTMASK=0`, and the shuffled control gives 6 twins (expected 0). With `SOFTMASK=1`
  the hot-spot copies pass and the control gives 2. `docs/FLANK_UNIQUENESS.md` (toy paragraph) still claims 0 and 0.
- **No LICENSE file**; `CITATION.cff` author is a placeholder; MANUAL §2 clones `SINEderella-dev`, which does not exist.
- **Resume after an interrupted `--add`/`--exclude`** assigns the source run's copy set and exits 0; `extracted.fasta`
  is written in place, so a truncated file counts as complete (SINEderella:977/1137/1270, step1:231).
- **`--add`/`--exclude` rebuild** does not re-apply `satellites/exclude_regions.bed`.
- **Satellites**: the array check reads only the first 12 units and excludes the whole run span; names with `/`
  are skipped by the satellite stage; `tools/array_order.py` unmarks a narrow array next to a long-period run.
- **sear**: copies longer than 500 bp across a 2,000-bp window step are lost or cut (`-W 3000` would fix it);
  `.2k.bnk` (1.25 × genome) is left in every run directory.
- **Publish**: `add_seed_row` runs twice (trim marks lost); old plates are never removed; the border scan measures
  flank noise at < 20 copies and rewrites the consensus even with a zero extension; 0-based header start counted twice.
- **Report**: unusable at phone width; nucleotide plots unreadable; the divergence spline crosses empty bins; plate
  row 2 is counted as a copy in the verdicts; no pipeline version or command in the report or manifest.
- **SINEderella_multi**: always exits 0; `summary --project DIR` deletes `DIR/summary`.
