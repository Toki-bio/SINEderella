# Pre-publication audit, 2026-10-14

Eight audits (step 1 / sear / satellites, steps 2–3, orchestrators and usability, report and plots, publish flow,
flankscan, tools and tests, bundled SubFam) were run on 37ce359 with synthetic genomes and the toy sets; the fixes
below were re-applied and re-tested on main (2afc55b). Earlier audits: AUDIT_2026-10-05.md, RELEASE_CHECK_2026-10-05.md.

## Still open

- **flankscan**: missing trf / minimap2 / dustmasker give empty results (`|| true`); a 5' flank clipped at a contig start is measured as full length;
  fs8 can stop when no conserved window is found; `report_flank_uniqueness.scan()` ignores its parameters; no `--help`.
- **Publish**: border-loop independence check before the extension; step 7 statistics (window sizes, ungapped identity, clipped windows);
  some MAFFT calls without `--threadit 0`; manifest without soft count or flanks.
- **Report**: the "No flanks" chip below 20 flanked copies; the alignment-table intro hard-codes 50 + 70 bp; thresholds table aborts on "NA".
- **Orchestrator**: positional arguments ignored in `--add`/`--exclude`/`--resume`; optional-stage failures are warnings only, no run log;
  `--resume --run` on a wrong directory copies scripts before checking it; `--resume` does not run step 6 or the publish step.
- **step 2 / 3**: contig names with `|` or `:`; asSINEment (legacy) not removed.
